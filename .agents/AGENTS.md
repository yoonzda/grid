# Project Rules

## UI & Design System Guidelines
- **No Emojis in UI Buttons & Controls**: Never use emojis (such as 👁️, 🎨, 📌, ⚙️, 📝, etc.) inside UI buttons, labels, tab titles, or property panel controls throughout this project. Use clean, professional text or SVG icons (Lucide React icons) instead.

## Git Workflow Guidelines
- **No Automatic Git Commit/Push**: Do not perform automatic `git commit` or `git push` after every code change. Only run git commit/push when explicitly requested by the user.
